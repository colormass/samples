Code samples for the use of the colormass 3D Ecosystem.

# Configurator

Make sure to serve the example via an HTTP server such as [this one](https://github.com/http-party/http-server) on port 8080 and use localhost when testing locally, otherwise the loading of the Configurator module will be blocked by the browser's CORS policy.

```bash
# server needs to run on port 8080
npx http-server --port 8080
```

You can test the sample projects at `http://localhost:8080`.
